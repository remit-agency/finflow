# S14 (part 1): MT940 import and import undo — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The owner or accountant uploads an MT940 statement, sees a preview (new / skipped / refused), picks a FinFlow account per statement, imports in steps of 25, and can undo the whole import from Settings → Imports. Importing the same file twice creates 0 new operations.

**Architecture:** A pure parser and planning rules in `lib/domain/import/` (no I/O, tagged results). A server module `lib/server/imports/` writes through the existing S09 pipeline (`createWithRules` → `createTransaction`, `bankSeen/{key}` marks, bank lock, S10 rules, S10b/S11 matching) and keeps one `imports/{id}` document per file run. Four routes (`preview`, `step`, `list`, `undo`) are thin adapters. UI: an `ImportDialog` opened from the journal toolbar and a Settings → Imports page.

**Tech Stack:** Next.js 16, React 19 (React Compiler lint: no setState in effect bodies), next-intl (uk/pl/en, identical keys, edit JSON by targeted text insertion, never parse and re-serialize), Firestore Admin, Vitest (does not typecheck — always run `npm run typecheck`), Playwright e2e on the Firestore emulator. tsconfig targets ES2017 (use `BigInt(...)`).

**Spec:** `docs/superpowers/specs/2026-11-19-s14-mt940-import-design.md` (read it first). Branch: `s14-mt940-import` (already created; the spec is committed there).

## Spec adjustments decided while planning (Task 0 writes them into the spec)

1. **The operation keeps `source: 'bank'`.** S10b (own transfers) and S11 (plan matching) select candidates by `source === 'bank'` plus the `bank` block (`lib/domain/transfers/pairs.ts:23`, `lib/domain/recurring/match.ts:35`). Giving file operations another source would need changes in both, and the spec requires that they "work as for bank operations". So a file operation has `source: 'bank'` and a `bank` block `{ importId, entryReference?, counterpartyName?, remittance? }` **without `accountRef`**. `BankInfo.accountRef` becomes optional and `importId` is added; exactly one of the two is set. `accountRef` has no consumer other than `map.ts` and `doc.ts` (checked by grep), so this is a two-file change.
2. **The key carries the ordinal of the operation, sent by the client.** The ordinal among identical operations is computed over the whole statement by the parser (preview), travels in each `ImportOp`, and the write step recomputes the key from `accountId` + the op's fields + its ordinal. The write step never trusts a client key. (A step has only ≤25 ops, so it cannot compute the ordinal itself.)
3. **One key formula for all operations:** `sha(['file', accountId, day, amountMinor, type, ref? ('ref', ref) : ('fp', name, remittance), ordinal])`. The day is part of the key even with a reference, because some banks reuse a constant customer reference.
4. **The opening balance is fitted at the end of the last step of a statement** (as S09's `finish` does), not in the first step. Emptiness of the account is judged on the first step that touches the account in this import and stored in `imports/{id}.fit.{accountId}` (`'pending' | 'no' | 'done'`).
5. **A per-account step lock** lives in a new server-only collection `importLocks/{accountId}` (same shape as the S09 `syncLock`). Rules: closed to clients by default; only the comment in `firestore.rules` changes.
6. **`imports` reads go through the API only** (`GET /imports`), so `firestore.rules` stay closed for `imports` too (only the data-shape comment changes). The spec's "readable by owner and accountant" is met by the route's role check.
7. **Preview takes the chosen accounts.** `POST /imports/preview { fileName, text, accountIds? }`: without `accountIds` it parses and suggests accounts; with them (one per statement, `null` allowed) it also marks each op `new | seen | bank | refused:<reason>`.
8. **File encoding.** Polish banks export MT940 in UTF-8 or Windows-1250. The browser decodes bytes with `decodeStatementBytes` (strict UTF-8, then `windows-1250`) before sending `text`.
9. **Reconciliation check.** `opening + Σ signed operations − closing` is computed per statement (`reconciliation`) and shown as a warning when ≠ 0; it is also the main correctness check of the parser against the owner's real files.
10. **Known risk (kept as the owner decided):** the overlap rule for bank-linked accounts requires equal references when both operations have one. Enable Banking `entry_reference` and an MT940 `//ref` are usually different strings, so for a bank-linked account most overlaps are NOT recognised when both sides have a reference. The rule is one function (`overlapsBank`); the final report must say how it behaved on real data.

```ts
export function parseBankInfo(v: unknown): BankInfo | null {
  if (!isRecord(v)) return null
  const bank: BankInfo = {}
  for (const key of ['accountRef', 'importId', 'entryReference', 'counterpartyName', 'remittance'] as const) {
    const value = v[key]
    if (typeof value === 'string') bank[key] = value
  }
  return bank.accountRef === undefined && bank.importId === undefined ? null : bank
}

function bankInfoToDoc(b: BankInfo): Record<string, string> {
  const doc: Record<string, string> = {}
  for (const key of ['accountRef', 'importId', 'entryReference', 'counterpartyName', 'remittance'] as const) {
    const value = b[key]
    if (value !== undefined) doc[key] = value
  }
  return doc
}
```

```ts
/**
 * Polish banks export MT940 as UTF-8 or Windows-1250. Strict UTF-8 first (a byte that is not valid UTF-8 throws), then
 * Windows-1250. Other code pages (CP852, ISO-8859-2) are not detected: their text still imports, with wrong letters.
 */
export function decodeStatementBytes(bytes: Uint8Array): { text: string; encoding: 'utf-8' | 'windows-1250' } {
  try {
    return { text: new TextDecoder('utf-8', { fatal: true }).decode(bytes), encoding: 'utf-8' }
  } catch {
    return { text: new TextDecoder('windows-1250').decode(bytes), encoding: 'windows-1250' }
  }
}
```

```ts
import type { ImportOp, RawOp } from './types'

function norm(s: string | null): string {
  return (s ?? '').replace(/\s+/g, ' ').trim().toLowerCase()
}

/** What makes two lines "the same operation" of one account: day, amount, direction, then the reference or else the text. */
export function opIdentityParts(op: RawOp): string[] {
  const head = [op.day, String(op.amountMinor), op.type]
  return op.reference !== null ? [...head, 'ref', op.reference] : [...head, 'fp', norm(op.counterpartyName), norm(op.remittance)]
}

/** Numbers the lines that share an identity, in file order (0, 1, 2 …). */
export function withOrdinals(ops: readonly RawOp[]): ImportOp[] {
  const seen = new Map<string, number>()
  return ops.map((op) => {
    const id = opIdentityParts(op).join('\u0001')
    const ordinal = seen.get(id) ?? 0
    seen.set(id, ordinal + 1)
    return { ...op, ordinal }
  })
}
```

```ts
import { isDay } from '@/lib/domain/ledger/days'
import { withOrdinals } from './identity'
import type { ParseIssue, ParseResult, ParsedStatement, RawOp, StatementBalance } from './types'

interface Rec {
  tag: string
  line: number
  lines: string[]
}

const TAG = /^:(\d{2}[A-Z]?):(.*)$/
/** `:61:` value day, optional entry day (mmdd), D/C/RD/RC, optional funds code, amount, `N`+type, customer ref, `//bank ref`. */
const L61 = /^(\d{6})(\d{4})?(RC|RD|C|D)[A-Z]?(\d{1,12}(?:,\d{0,2})?)[NFS]([A-Z0-9]{3})(.*?)(?:\/\/(.*))?$/
const BALANCE = /^([CD])(\d{6})([A-Z]{3})(\d{1,12}(?:,\d{0,2})?)$/
/** The Polish dialects of `:86:`: a three digit code, then `~NN` or `?NN` sub-fields. */
const STRUCTURED = /^(?:\d{3})?[~?]\d{2}/
/** Sub-fields that hold the payment title, and those that hold the other party's name (Polish ZBP format). */
const TITLE_FIELDS = ['20', '21', '22', '23', '24', '25', '60', '61', '62', '63'] as const
const NAME_FIELDS = ['32', '33'] as const

/** "1000,50" -> 100050; "1000," and "1000" are whole units. Null for anything else. */
function minorOf(raw: string): number | null {
  const m = /^(\d{1,12})(?:,(\d{0,2}))?$/.exec(raw)
  if (m === null) return null
  return Number(m[1]) * 100 + Number((m[2] ?? '').padEnd(2, '0'))
}

/** yymmdd -> YYYY-MM-DD (years 2000-2099); null when it is not a real day. */
function dayOf(yymmdd: string): string | null {
  const day = `20${yymmdd.slice(0, 2)}-${yymmdd.slice(2, 4)}-${yymmdd.slice(4, 6)}`
  return isDay(day) ? day : null
}

function balanceOf(text: string): StatementBalance | null {
  const m = BALANCE.exec(text.trim())
  if (m === null) return null
  const day = dayOf(m[2])
  const minor = minorOf(m[4])
  if (day === null || minor === null) return null
  return { amountMinor: m[1] === 'D' && minor !== 0 ? -minor : minor, day, currency: m[3] }
}

/** The entry day mmdd takes the value day's year, moved by one when the two straddle a year end. */
function entryDay(valueDay: string, mmdd: string): string | null {
  const vy = Number(valueDay.slice(0, 4))
  const vm = Number(valueDay.slice(5, 7))
  const diff = Number(mmdd.slice(0, 2)) - vm
  const year = diff > 6 ? vy - 1 : diff < -6 ? vy + 1 : vy
  const day = `${year}-${mmdd.slice(0, 2)}-${mmdd.slice(2, 4)}`
  return isDay(day) ? day : null
}

/** `:25:` as an identity: no spaces, no leading slash, upper case; an NRB (26 digits) gets the `PL` prefix. */
export function normalizeSource(raw: string): string {
  const flat = raw.replace(/\s+/g, '').replace(/^\//, '').toUpperCase().replace(/\//g, '')
  return /^\d{26}$/.test(flat) ? `PL${flat}` : flat
}

function clean(s: string): string | null {
  const t = s.replace(/\s+/g, ' ').trim()
  return t === '' ? null : t
}

/** The `:86:` text of a line: the name and the title when the dialect is a Polish one, else the whole text as the title. */
function narrative(lines: readonly string[]): { counterpartyName: string | null; remittance: string | null } {
  if (lines.length === 0) return { counterpartyName: null, remittance: null }
  if (!STRUCTURED.test(lines[0].trim())) return { counterpartyName: null, remittance: clean(lines.join(' ')) }
  // Sub-fields are cut at fixed widths, so a line break may fall inside one: the lines are joined without a separator.
  const parts = lines.join('').split(/[~?](\d{2})/)
  const fields = new Map<string, string>()
  for (let i = 1; i + 1 < parts.length; i += 2) fields.set(parts[i], `${fields.get(parts[i]) ?? ''}${parts[i + 1]}`)
  const join = (codes: readonly string[]) => clean(codes.map((c) => fields.get(c)?.trim() ?? '').filter((s) => s !== '').join(' '))
  return { counterpartyName: join(NAME_FIELDS), remittance: join(TITLE_FIELDS) ?? clean(fields.get('00') ?? '') }
}

function toRecords(text: string): { recs: Rec[]; firstLine: number } {
  let src = text.replace(/^\uFEFF/, '').replace(/\r\n?/g, '\n')
  let base = 0
  const body = src.indexOf('{4:')
  if (src.trimStart().startsWith('{1:') && body >= 0) {
    base = src.slice(0, body + 3).split('\n').length - 1
    src = src.slice(body + 3)
  }
  const recs: Rec[] = []
  let cur: Rec | null = null
  src.split('\n').forEach((raw, i) => {
    const line = raw.trimEnd()
    const lineNo = base + i + 1
    if (line === '-}' || line === '-' || line === '}') {
      cur = null
      return
    }
    const m = TAG.exec(line)
    if (m !== null) {
      cur = { tag: m[1], line: lineNo, lines: [m[2]] }
      recs.push(cur)
    } else if (cur !== null && line !== '') {
      cur.lines.push(line)
    }
  })
  return { recs, firstLine: base + 1 }
}

function parse61(rec: Rec): RawOp | null {
  const m = L61.exec(rec.lines[0].trim())
  if (m === null) return null
  const valueDay = dayOf(m[1])
  const minor = minorOf(m[4])
  if (valueDay === null || minor === null) return null
  const day = (m[2] !== undefined ? entryDay(valueDay, m[2]) : null) ?? valueDay
  const bank = clean(m[7] ?? '')
  const customer = clean(m[6])
  return {
    day,
    type: m[3] === 'C' || m[3] === 'RD' ? 'income' : 'expense',
    amountMinor: minor,
    reference: bank ?? (customer !== null && customer.toUpperCase() !== 'NONREF' ? customer : null),
    counterpartyName: null,
    remittance: null,
  }
}

interface Draft {
  source: string | null
  number: string | null
  opening: StatementBalance | null
  closing: StatementBalance | null
  ops: RawOp[]
}

function finish(d: Draft, index: number): ParsedStatement {
  const signed = d.ops.reduce((sum, o) => sum + (o.type === 'income' ? o.amountMinor : -o.amountMinor), 0)
  return {
    index,
    source: d.source,
    number: d.number,
    currency: d.opening?.currency ?? d.closing?.currency ?? null,
    opening: d.opening,
    closing: d.closing,
    operations: withOrdinals(d.ops),
    reconciliation: d.opening !== null && d.closing !== null ? d.opening.amountMinor + signed - d.closing.amountMinor : null,
  }
}

/**
 * Reads an MT940 file: statements start at `:20:` (or at the first tag when a file has no `:20:`), a `:86:` belongs to the
 * `:61:` before it. A line that cannot be read becomes an issue with its line number and the rest of the statement is kept.
 * Pure: no I/O, no clock. Byte decoding is `decodeStatementBytes`.
 */
export function parseMt940(text: string): ParseResult {
  const { recs, firstLine } = toRecords(text)
  const issues: ParseIssue[] = []
  const statements: ParsedStatement[] = []
  let draft: Draft | null = null
  let pending: RawOp | null = null
  let afterClosing = false

  const close = () => {
    if (draft !== null) statements.push(finish(draft, statements.length))
    draft = null
    pending = null
    afterClosing = false
  }
  const open = (): Draft => {
    draft = { source: null, number: null, opening: null, closing: null, ops: [] }
    return draft
  }

  for (const rec of recs) {
    if (rec.tag === '20') {
      close()
      open()
      continue
    }
    const d = draft ?? open()
    const first = rec.lines[0].trim()
    switch (rec.tag) {
      case '25':
        d.source = normalizeSource(first)
        break
      case '28C':
        d.number = clean(first)
        break
      case '60F':
      case '60M': {
        const b = balanceOf(first)
        if (b === null) issues.push({ code: 'bad_balance', line: rec.line, tag: rec.tag })
        else d.opening ??= b
        break
      }
      case '62F':
      case '62M': {
        const b = balanceOf(first)
        if (b === null) issues.push({ code: 'bad_balance', line: rec.line, tag: rec.tag })
        else if (rec.tag === '62F' || d.closing === null) d.closing = b
        pending = null
        afterClosing = true
        break
      }
      case '61': {
        const op = parse61(rec)
        if (op === null) {
          issues.push({ code: 'bad_61', line: rec.line, tag: '61' })
          pending = null
        } else {
          d.ops.push(op)
          pending = op
        }
        break
      }
      case '86': {
        if (pending !== null) {
          Object.assign(pending, narrative(rec.lines))
          pending = null
        } else if (!afterClosing && d.ops.length === 0) {
          issues.push({ code: 'orphan_86', line: rec.line, tag: '86' })
        }
        break
      }
      default:
        break
    }
  }
  close()
  if (statements.length === 0) issues.push({ code: 'no_statement', line: firstLine })
  return { statements, issues }
}
```

```ts
  currency: string | null
  from: string | null

function parseOp(v: unknown, at: string): Parsed<ImportOp> {
  if (!isRecord(v)) return { ok: false, field: at }

  if (body.importId !== undefined && !isId(body.importId)) return { ok: false, field: 'importId' }
  if (typeof body.fileName !== 'string' || body.fileName.trim() === '' || body.fileName.length > 255) return { ok: false, field: 'fileName' }

  if (!isRecord(s)) return { ok: false, field: 'statement' }

  const to = s.to === null || isDay(s.to) ? (s.to as string | null) : undefined
  const closing = s.closingMinor === null || (Number.isSafeInteger(s.closingMinor) && Math.abs(s.closingMinor as number) <= MAX_MINOR) ? (s.closingMinor as number | null) : undefined
  if (source === undefined) return { ok: false, field: 'statement.source' }
```

```ts
export const UNDO_STEP = 25

export interface UndoResult {
  deleted: number
  kept: Array<{ id: string; reason: string }>
  next: string | null
  done: boolean
}

export async function undoStep(deps: ImportDeps, orgId: string, uid: string, importId: string, cursor?: string): Promise<UndoResult> {
  const ref = importsCol(deps.db, orgId).doc(importId)
  const doc = await readImport(ref)                 // ImportError('not_found') when missing or malformed
  if (doc.status === 'undone') return { deleted: 0, kept: [], next: null, done: true }
  if (doc.status === 'applied') await ref.update({ status: 'undoing' })

  let q = transactionsCol(deps.db, orgId).where('bank.importId', '==', importId).orderBy(FieldPath.documentId()).limit(UNDO_STEP)
  if (cursor !== undefined) q = q.startAfter(cursor)
  const snap = await q.get()
  let deleted = 0
  const kept: UndoResult['kept'] = []
  for (const d of snap.docs) {
    // Untouched since the import: the document was never written after it was created (Firestore times).
    if (!d.updateTime.isEqual(d.createTime)) {
      kept.push({ id: d.id, reason: 'changed' })
      continue
    }
    const key = d.id.startsWith(BANK_CLIENT_ID_PREFIX) ? d.id.slice(BANK_CLIENT_ID_PREFIX.length) : null
    const markRef = key === null ? null : bankSeenCol(deps.db, orgId).doc(key)
    const markSnap = markRef === null ? null : await markRef.get()
    try {
      // The mark goes first: a crash between the two leaves an operation without a mark, which this step finds again
      // (the reverse order would leave a mark without an operation, and the file could never be imported again).
      if (markSnap?.exists) await markRef!.delete()
      await deleteTransaction(deps.ledger, orgId, uid, d.id, 'import-undo')
      deleted++
    } catch (e) {
      if (!(e instanceof LedgerError)) throw e
      // The operation stays; its mark is written back (same data) so a re-import does not duplicate it.
      if (markSnap?.exists) await markRef!.set(markSnap.data()!)
      kept.push({ id: d.id, reason: e.code })
    }
  }
  const last = snap.docs.length < UNDO_STEP
  const next = last ? null : snap.docs[snap.docs.length - 1].id
  const progress = { 'undo.deleted': FieldValue.increment(deleted), 'undo.kept': FieldValue.increment(kept.length) }
  if (last) await ref.update({ ...progress, status: 'undone', undoneAt: Timestamp.fromDate(deps.now()) })
  else await ref.update(progress)
  return { deleted, kept, next, done: last }
}
```

(b) Restoring a mark after a refused delete: instead of deleting the mark first, read the mark (`get`) first and re-`set` the same data in the catch. (c) A kept document's `d.id` after a refused delete is in `kept` with the ledger code, e.g. `ledger_busy` — the client shows "try again" for any reason other than `changed`. (d) `updateTime`/`createTime` come from the `QueryDocumentSnapshot`; check the emulator returns `updateTime > createTime` after `updateTransaction` (the test in step 1 proves it). (e) The query needs no new index: one equality filter on a map field plus ordering by `__name__` (automatic).
