# S10: Автоправила (категорія і контрагент). План реалізації

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Власник чи бухгалтер задає правила («призначення містить ORLEN, BP, SHELL → категорія Паливо»), і нові банківські операції (також у фоновому оновленні S09b) одразу отримують категорію й контрагента; кнопка «Застосувати до наявних» спершу показує «буде змінено N», потім заповнює порожні поля наявних операцій. Правило ніколи не перезаписує вибране людиною.

**Architecture:** Чиста частина `lib/domain/rules/` (нормалізація тексту на спільному `foldDiacritics`, типи, валідація входу, `applyRules`, «неробочі» дії, мапінг документа). Сервер `lib/server/rules/` пише `organizations/{org}/rules/{ruleId}` в одній Admin-транзакції з записом `audit` (`rule.create|update|delete|order`), читає правила для імпорту й кроків застосування. Ledger отримує серверний параметр `WriteExtras` (`autoRules`, `expectVersion`): операція зберігає слід `autoRules: [{ id, name }]`, запис `audit` має `via: 'rule'`, ручна зміна категорії чи контрагента слід стирає. `syncStep` читає правила один раз за крок і пише операцію через `createWithRules` (з відкатом до запису без дій правила). Маршрути `app/api/orgs/[orgId]/rules/**`, у браузері розділ налаштувань «Правила», редактор у діалозі, діалог «Застосувати до наявних» і чип «за правилом» у журналі.

**Tech Stack:** Next.js 16 route handlers, firebase-admin (транзакції, запити в порядку журналу), Vitest (unit + інтеграційні на емуляторі Firestore + правила Firestore), Playwright (емулятори + підроблений банк), next-intl (uk/pl/en).

## Spec corrections

1. **Код помилки для некоректних даних.** Спека: «Помилки в стилі S06: `422` з полем (`field`)». У коді S06 і ledger некоректні дані це `400 invalid_input` з `field` (`lib/server/counterparties/http.ts`, `lib/server/ledger/http.ts`; тест `tests/unit/api/counterparties/routes.test.ts` очікує 400). План іде за кодом: `400 invalid_input` з `field`; `422` лишається для `category_not_found`, `counterparty_not_found`, `counterparty_archived`.
2. **«Перевірити» читає до 2000 операцій без категорії чи контрагента (один запит).** Firestore не вміє запитати «поле відсутнє», тож один запит читає останні 2000 операцій у порядку журналу, а відбір «без категорії або контрагента» йде в пам'яті. `scanned` у відповіді означає кількість таких кандидатів серед прочитаних, `capped` означає, що запит повернув рівно 2000 документів (далі можуть бути ще).

## Рішення плану (в межах спеки)

- **Неробоча дія** відкидається до виклику `applyRules` (`withoutUnusableActions`), бо чиста функція не знає Firestore; інша дія того ж правила працює. `applyRules(rules, operation)` лишається з двома аргументами, як у спеці.
- **Перевірка дій при збереженні:** create перевіряє обидві дії; `PATCH` перевіряє лише дію, що змінилася (або категорію, коли змінився `type`), як ledger із контрагентом. Інакше неробоче правило не можна було б навіть вимкнути чи перейменувати.
- **«Ніколи не перезаписує» при застосуванні до наявних:** крок передає в `updateTransaction` версію документа, яку бачив (`expectVersion`); якщо людина щось змінила після читання, запис відмовляє з `conflict` і рахується у `failed`.
- **Правила в імпорті** читаються ліниво: лише коли в кроці з'явилася нова операція (крок без нових операцій не читає правил).
- **Права в інтерфейсі:** окремої дії в `lib/shell/permissions.ts` не додаємо: редагування правил це `data.write` (власник і бухгалтер), як контрагенти; розділ бачать усі члени.
- **Браузер читає правила через `GET /rules`** (там обчислено мітку «неробоче»), а не прямою підпискою Firestore, хоча правила Firestore дають членам читання (як `categories`).
- **Тексти з кількістю** записано через двокрапку («Буде змінено операцій: {count}»), як `journal.delete.title` в uk, щоб не потрібні були ICU-множини.

```ts
/**
 * Latin letters without their diacritics (`ł` counts as `l`, `ó` as `o`), case kept. Other scripts keep their letters:
 * Cyrillic `й` stays distinct from `и`; marks left over after recomposition (a stress mark, say) are dropped.
 * The one fold of the counterparty name key (S06) and of the rule text matching (S10).
 */
export function foldDiacritics(text: string): string {
  return text
    .normalize('NFD')
    .replace(/(\p{Script=Latin})\p{M}+/gu, '$1')
    .normalize('NFC')
    // What is still a combining mark now (a stress mark, say) is not part of a precomposed letter: `й` and `ї` stay.
    .replace(/\p{M}+/gu, '')
    .replace(/ł/g, 'l')
    .replace(/Ł/g, 'L')
}
```

```ts
import { foldDiacritics } from '@/lib/domain/text/fold'

/**
 * The comparable form of a text for the rules: Latin diacritics folded as in the counterparty name key, lower case,
 * every run of characters that are not letters or digits one space, trimmed. '' for a text with no letter or digit.
 */
export function normalizeRuleText(text: string): string {

    .toLowerCase()
    .replace(/[^\p{L}\p{N}]+/gu, ' ')
    .trim()
}
```

```ts
/**
 * The trace an update leaves (S10). A write by the rules adds its rules to the trace (each once). Otherwise a change of
 * the category or the counterparty is a person's choice and removes the trace; any other edit keeps it.
 */
function autoRulesAfter(prior: LedgerTransaction, next: LedgerTransaction, given: readonly AutoRuleRef[]): AutoRuleRef[] | undefined {
  if (given.length > 0) {
    const merged = [...(prior.autoRules ?? [])]
    for (const r of given) if (!merged.some((m) => m.id === r.id)) merged.push({ id: r.id, name: r.name })
    return merged
  }
  if (prior.categoryId !== next.categoryId || prior.counterpartyId !== next.counterpartyId) return undefined
  return prior.autoRules
}
```

```ts
  deps: LedgerDeps,
  orgId: string,
  uid: string,
  txId: string,
  patch: TransactionPatch,
  extras: WriteExtras = {},
): Promise<WriteResult> {
  const prior = await loadPrior(deps, orgId, txId)
  // The rules read the operation at `expectVersion`: anything a person did since then wins (S10).
  if (extras.expectVersion !== undefined && !prior.version.isEqual(extras.expectVersion)) throw new LedgerError('conflict')
  const next = await prepare(deps, orgId, txId, applyPatch(toRawInput(prior.tx), patch))
  if (prior.tx.bank !== undefined) {
    assertBankUnlocked(prior.tx, next.tx)
    // toRawInput never carries `bank`, so an edit keeps the provenance from the prior document.
    next.tx = { ...next.tx, bank: prior.tx.bank }
  }
  const given = extras.autoRules ?? []
  // toRawInput never carries `autoRules` either: the trace is decided here.
  const autoRules = autoRulesAfter(prior.tx, next.tx, given)
  if (autoRules !== undefined) next.tx = { ...next.tx, autoRules }
  return commit(deps, orgId, uid, { action: 'tx.update', txId, prior, next, via: given.length > 0 ? 'rule' : undefined })
```

```ts
import { decodeCursor, type JournalKey } from '@/lib/domain/journal/order'
import { isId } from '@/lib/domain/ledger/guards'
import { MAX_MINOR, isMinor } from '@/lib/domain/ledger/money'
import { LEDGER_CURRENCIES } from '@/lib/domain/ledger/types'
import { asRecord, bad, onlyKeys } from './guards'
import { normalizeRuleText } from './normalize'
import {
  MAX_CONDITIONS,
  MAX_RULE_ACCOUNTS,
  MAX_RULES,
  MAX_VALUES,
  RULE_NAME_MAX,
  RULE_TYPES,
  TEXT_OPS,
  VALUE_MAX,
  type AccountCondition,
  type RuleActions,
  type RuleCondition,
  type RuleType,
  type TextCondition,
  type TextOp,
} from './types'

/** An amount condition as a request may send it: without a currency it takes the company currency (`withCurrency`). */
export interface AmountConditionInput {
  kind: 'amount'
  currency?: string
  minMinor?: number
  maxMinor?: number
}

export type RuleConditionInput = TextCondition | AccountCondition | AmountConditionInput

/** A validated create (and preview) request. */
export interface RuleInput {
  name: string
  type: RuleType
  active: boolean
  conditions: RuleConditionInput[]
  actions: RuleActions
}

/** A validated PATCH: only the fields given, at least one. `actions` replaces both actions. */
export interface RulePatch {
  name?: string
  type?: RuleType
  active?: boolean
  conditions?: RuleConditionInput[]
  actions?: RuleActions
}

const RULE_KEYS = ['name', 'type', 'active', 'conditions', 'actions'] as const

function ruleName(v: unknown): string {
  if (typeof v !== 'string') bad('name')
  const text = v.replace(/\s+/g, ' ').trim()
  if (text.length < 1 || text.length > RULE_NAME_MAX) bad('name')
  return text
}

function ruleType(v: unknown): RuleType {
  if (!(RULE_TYPES as readonly unknown[]).includes(v)) bad('type')
  return v as RuleType
}

function active(v: unknown): boolean {
  if (typeof v !== 'boolean') bad('active')
  return v
}

function words(v: unknown, field: string): string[] {
  if (!Array.isArray(v) || v.length < 1 || v.length > MAX_VALUES) bad(field)
  return v.map((item) => {
    if (typeof item !== 'string') bad(field)
    const text = item.replace(/\s+/g, ' ').trim()
    // A word with no letter or digit would match everything after normalisation.
    if (text.length < 1 || text.length > VALUE_MAX || normalizeRuleText(text) === '') bad(field)
    return text
  })
}

function bound(v: unknown, field: string): number | undefined {
  if (v === undefined) return undefined
  if (!isMinor(v) || v < 0 || v > MAX_MINOR) bad(field)
  return v
}

function condition(v: unknown, i: number): RuleConditionInput {
  const p = `conditions.${i}.`
  const r = asRecord(v, `conditions.${i}`)
  if (r.kind === 'text') {
    onlyKeys(r, ['kind', 'op', 'values'], p)
    if (!(TEXT_OPS as readonly unknown[]).includes(r.op)) bad(`${p}op`)
    return { kind: 'text', op: r.op as TextOp, values: words(r.values, `${p}values`) }
  }
  if (r.kind === 'account') {
    onlyKeys(r, ['kind', 'accountIds'], p)
    const ids = r.accountIds
    if (!Array.isArray(ids) || ids.length < 1 || ids.length > MAX_RULE_ACCOUNTS) bad(`${p}accountIds`)
    if (!ids.every((id) => isId(id)) || new Set(ids).size !== ids.length) bad(`${p}accountIds`)
    return { kind: 'account', accountIds: ids as string[] }
  }
  if (r.kind === 'amount') {
    onlyKeys(r, ['kind', 'currency', 'minMinor', 'maxMinor'], p)
    if (r.currency !== undefined && !(LEDGER_CURRENCIES as readonly unknown[]).includes(r.currency)) bad(`${p}currency`)
    const minMinor = bound(r.minMinor, `${p}minMinor`)
    const maxMinor = bound(r.maxMinor, `${p}maxMinor`)
    if (minMinor === undefined && maxMinor === undefined) bad(`${p}minMinor`)
    if (minMinor !== undefined && maxMinor !== undefined && minMinor > maxMinor) bad(`${p}maxMinor`)
    const out: AmountConditionInput = { kind: 'amount' }
    if (r.currency !== undefined) out.currency = r.currency as string
    if (minMinor !== undefined) out.minMinor = minMinor
    if (maxMinor !== undefined) out.maxMinor = maxMinor
    return out
  }
  return bad(`${p}kind`)
}

function conditions(v: unknown): RuleConditionInput[] {
  if (!Array.isArray(v) || v.length < 1 || v.length > MAX_CONDITIONS) bad('conditions')
  return v.map((c, i) => condition(c, i))
}

function actions(v: unknown): RuleActions {
  const r = asRecord(v, 'actions')
  onlyKeys(r, ['categoryId', 'counterpartyId'], 'actions.')
  const out: RuleActions = {}
  if (r.categoryId !== undefined) {
    if (!isId(r.categoryId)) bad('actions.categoryId')
    out.categoryId = r.categoryId
  }
  if (r.counterpartyId !== undefined) {
    if (!isId(r.counterpartyId)) bad('actions.counterpartyId')
    out.counterpartyId = r.counterpartyId
  }
  if (out.categoryId === undefined && out.counterpartyId === undefined) bad('actions')
  return out
}

export function parseRuleInput(body: unknown): RuleInput {
  const r = asRecord(body)
  onlyKeys(r, RULE_KEYS)
  return {
    name: ruleName(r.name),
    type: ruleType(r.type),
    active: r.active === undefined ? true : active(r.active),
    conditions: conditions(r.conditions),
    actions: actions(r.actions),
  }
}

export function parseRulePatch(body: unknown): RulePatch {
  const r = asRecord(body)
  onlyKeys(r, RULE_KEYS)
  if (Object.keys(r).length === 0) bad('body')
  const out: RulePatch = {}
  if (r.name !== undefined) out.name = ruleName(r.name)
  if (r.type !== undefined) out.type = ruleType(r.type)
  if (r.active !== undefined) out.active = active(r.active)
  if (r.conditions !== undefined) out.conditions = conditions(r.conditions)
  if (r.actions !== undefined) out.actions = actions(r.actions)
  return out
}

/** The stored conditions: an amount condition without a currency takes the company currency. */
export function withCurrency(list: readonly RuleConditionInput[], baseCurrency: string): RuleCondition[] {
  return list.map((c) => (c.kind === 'amount' ? { ...c, currency: c.currency ?? baseCurrency } : c))
}

/** `POST /rules/order`: all the company's rule ids in the new order. */
export function parseOrderRequest(body: unknown): { ids: string[] } {
  const r = asRecord(body)
  onlyKeys(r, ['ids'])
  const ids = r.ids
  if (!Array.isArray(ids) || ids.length < 1 || ids.length > MAX_RULES) bad('ids')
  if (!ids.every((id) => isId(id)) || new Set(ids).size !== ids.length) bad('ids')
  return { ids: ids as string[] }
}

export type ApplyMode = 'check' | 'apply'

/** `POST /rules/apply`: the mode and the cursor of the previous step (absent on the first one). */
export function parseApplyRequest(body: unknown): { mode: ApplyMode; cursor: JournalKey | null } {
  const r = asRecord(body)
  onlyKeys(r, ['mode', 'cursor'])
  if (r.mode !== 'check' && r.mode !== 'apply') bad('mode')
  const mode = r.mode as ApplyMode
  if (r.cursor === undefined) return { mode, cursor: null }
  const cursor = typeof r.cursor === 'string' ? decodeCursor(r.cursor) : null
  if (cursor === null) bad('cursor')
  return { mode, cursor }
}

/** `POST /rules/preview`: a draft rule, validated like a create. */
export function parsePreviewRequest(body: unknown): { rule: RuleInput } {
  const r = asRecord(body)
  onlyKeys(r, ['rule'])
  return { rule: parseRuleInput(r.rule) }
}
```

```ts
import type { LedgerTransaction } from '@/lib/domain/ledger/types'
import { normalizeRuleText } from './normalize'
import type { Rule, RuleCondition, RuleOperation, RuleOutcome, TextCondition } from './types'

/** The normalised words of a text condition, computed once per condition object (a step applies 50 rules to 200 operations). */
const WORDS = new WeakMap<TextCondition, string[]>()

function wordsOf(c: TextCondition): string[] {
  let words = WORDS.get(c)
  if (words === undefined) {
    words = c.values.map(normalizeRuleText).filter((w) => w !== '')
    WORDS.set(c, words)
  }
  return words
}

/** The texts the rules look at (the bank's payment details, its name for the other party, the comment), normalised; empty ones left out. */
function textsOf(op: RuleOperation): string[] {
  return [op.remittance, op.bankName, op.description]
    .filter((t): t is string => typeof t === 'string')
    .map(normalizeRuleText)
    .filter((t) => t !== '')
}

function holds(c: RuleCondition, op: RuleOperation, texts: readonly string[]): boolean {
  switch (c.kind) {
    case 'text': {
      const words = wordsOf(c)
      if (c.op === 'equals') return words.some((w) => texts.includes(w))
      // Each text separately: a word never runs across the end of one text and the start of the next.
      const found = words.some((w) => texts.some((t) => t.includes(w)))
      return c.op === 'contains' ? found : !found
    }
    case 'account':
      return c.accountIds.includes(op.accountId)
    case 'amount':
      return (
        op.currency === c.currency &&
        (c.minMinor === undefined || op.amountMinor >= c.minMinor) &&
        (c.maxMinor === undefined || op.amountMinor <= c.maxMinor)
      )
  }
}

function matchesWith(rule: Rule, op: RuleOperation, texts: readonly string[]): boolean {
  return rule.active && rule.type === op.type && rule.conditions.every((c) => holds(c, op, texts))
}

/** True when the rule is active, of the operation's type, and every one of its conditions holds. */
export function ruleMatches(rule: Rule, op: RuleOperation): boolean {
  return matchesWith(rule, op, textsOf(op))
}

/** The order the rules are applied in: `order` ascending, then creation time, then id. A new array. */
export function sortRules(rules: readonly Rule[]): Rule[] {
  return [...rules].sort((a, b) => a.order - b.order || a.createdAtMs - b.createdAtMs || (a.id < b.id ? -1 : a.id > b.id ? 1 : 0))
}

/**
 * What the rules give an operation. Each empty field (category, counterparty) is filled by the first matching rule that
 * has that action; a field that is already set is never touched. `applied` lists only the rules that filled something.
 * Unusable actions must be removed before (`withoutUnusableActions`).
 */
export function applyRules(rules: readonly Rule[], op: RuleOperation): RuleOutcome {
  const out: RuleOutcome = { applied: [] }
  if (op.type === 'transfer') return out
  let needCategory = op.categoryId === undefined
  let needCounterparty = op.counterpartyId === undefined
  if (!needCategory && !needCounterparty) return out
  const texts = textsOf(op)
  for (const rule of sortRules(rules)) {
    if (!needCategory && !needCounterparty) break
    if (!matchesWith(rule, op, texts)) continue
    let filled = false
    if (needCategory && rule.actions.categoryId !== undefined) {
      out.categoryId = rule.actions.categoryId
      needCategory = false
      filled = true
    }
    if (needCounterparty && rule.actions.counterpartyId !== undefined) {
      out.counterpartyId = rule.actions.counterpartyId
      needCounterparty = false
      filled = true
    }
    if (filled) out.applied.push({ id: rule.id, name: rule.name })
  }
  return out
}

/** A stored operation as the rules see it. */
export function ruleOperationOf(tx: LedgerTransaction): RuleOperation {
  const op: RuleOperation = { type: tx.type, accountId: tx.accountId, currency: tx.currency, amountMinor: tx.amountMinor }
  if (tx.bank?.remittance !== undefined) op.remittance = tx.bank.remittance
  if (tx.bank?.counterpartyName !== undefined) op.bankName = tx.bank.counterpartyName
  if (tx.description !== undefined) op.description = tx.description
  if (tx.categoryId !== undefined) op.categoryId = tx.categoryId
  if (tx.counterpartyId !== undefined) op.counterpartyId = tx.counterpartyId
  return op
}
```

```ts
import type { ActionTargets, Rule, RuleActions, UnusableAction } from './types'

/** The actions of a rule that cannot work now (shown as «неробоче»); [] when both can. */
export function unusableActions(rule: Pick<Rule, 'type' | 'actions'>, targets: ActionTargets): UnusableAction[] {
  const out: UnusableAction[] = []
  const { categoryId, counterpartyId } = rule.actions
  if (categoryId !== undefined && targets.categories.get(categoryId) !== rule.type) out.push('category')
  if (counterpartyId !== undefined) {
    const counterparty = targets.counterparties.get(counterpartyId)
    if (counterparty === undefined || counterparty.archived) out.push('counterparty')
  }
  return out
}

/** The rules with their unusable actions removed: the other action of such a rule still works. */
export function withoutUnusableActions(rules: readonly Rule[], targets: ActionTargets): Rule[] {
  return rules.map((rule) => {
    const unusable = unusableActions(rule, targets)
    if (unusable.length === 0) return rule
    const actions: RuleActions = { ...rule.actions }
    if (unusable.includes('category')) delete actions.categoryId
    if (unusable.includes('counterparty')) delete actions.counterpartyId
    return { ...rule, actions }
  })
}
```

```ts
import { isMinor } from '@/lib/domain/ledger/money'
import {
  MAX_CONDITIONS,
  RULE_TYPES,
  TEXT_OPS,
  type AmountCondition,
  type Rule,
  type RuleActions,
  type RuleCondition,
  type RuleType,
  type TextOp,
} from './types'

export const RULE_SCHEMA_VERSION = 1

function isRecord(v: unknown): v is Record<string, unknown> {
  return typeof v === 'object' && v !== null && !Array.isArray(v)
}

function nonEmptyStrings(v: unknown): string[] | null {
  return Array.isArray(v) && v.length > 0 && v.every((s) => typeof s === 'string' && s !== '') ? [...(v as string[])] : null
}

function conditionToDoc(c: RuleCondition): Record<string, unknown> {
  if (c.kind === 'text') return { kind: 'text', op: c.op, values: [...c.values] }
  if (c.kind === 'account') return { kind: 'account', accountIds: [...c.accountIds] }
  const doc: Record<string, unknown> = { kind: 'amount', currency: c.currency }
  if (c.minMinor !== undefined) doc.minMinor = c.minMinor
  if (c.maxMinor !== undefined) doc.maxMinor = c.maxMinor
  return doc
}

/** The stored fields of a rule (no id, no timestamps, no orgId: the writer adds those). Never contains `undefined`. */
export function ruleToDoc(rule: Rule): Record<string, unknown> {
  const actions: Record<string, string> = {}
  if (rule.actions.categoryId !== undefined) actions.categoryId = rule.actions.categoryId
  if (rule.actions.counterpartyId !== undefined) actions.counterpartyId = rule.actions.counterpartyId
  return {
    schemaVersion: RULE_SCHEMA_VERSION,
    name: rule.name,
    type: rule.type,
    active: rule.active,
    order: rule.order,
    conditions: rule.conditions.map(conditionToDoc),
    actions,
  }
}

function bound(v: unknown): number | undefined | null {
  if (v === undefined) return undefined
  return isMinor(v) && v >= 0 ? v : null
}

function parseCondition(v: unknown): RuleCondition | null {
  if (!isRecord(v)) return null
  if (v.kind === 'text') {
    const values = nonEmptyStrings(v.values)
    if (!(TEXT_OPS as readonly unknown[]).includes(v.op) || values === null) return null
    return { kind: 'text', op: v.op as TextOp, values }
  }
  if (v.kind === 'account') {
    const accountIds = nonEmptyStrings(v.accountIds)
    return accountIds === null ? null : { kind: 'account', accountIds }
  }
  if (v.kind === 'amount') {
    if (typeof v.currency !== 'string' || v.currency === '') return null
    const minMinor = bound(v.minMinor)
    const maxMinor = bound(v.maxMinor)
    if (minMinor === null || maxMinor === null || (minMinor === undefined && maxMinor === undefined)) return null
    const c: AmountCondition = { kind: 'amount', currency: v.currency }
    if (minMinor !== undefined) c.minMinor = minMinor
    if (maxMinor !== undefined) c.maxMinor = maxMinor
    return c
  }
  return null
}

function parseActions(v: unknown): RuleActions | null {
  if (!isRecord(v)) return null
  const out: RuleActions = {}
  for (const key of ['categoryId', 'counterpartyId'] as const) {
    const value = v[key]
    if (value === undefined) continue
    if (typeof value !== 'string' || value === '') return null
    out[key] = value
  }
  return out.categoryId === undefined && out.counterpartyId === undefined ? null : out
}

/** Milliseconds of a Firestore Timestamp (anything with a `toMillis` method), 0 otherwise. */
function millisOf(v: unknown): number {
  if (!isRecord(v) || typeof v.toMillis !== 'function') return 0
  const ms: unknown = (v as { toMillis: () => unknown }).toMillis()
  return typeof ms === 'number' && Number.isFinite(ms) ? ms : 0
}

/** Strict reader: null for a document that is not a schema 1 rule (such a document is never listed or applied). */
export function parseRule(id: string, data: unknown): Rule | null {
  if (!isRecord(data) || data.schemaVersion !== RULE_SCHEMA_VERSION) return null
  const { name, type, active, order } = data
  if (typeof name !== 'string' || name === '' || !(RULE_TYPES as readonly unknown[]).includes(type)) return null
  if (typeof active !== 'boolean' || typeof order !== 'number' || !Number.isSafeInteger(order)) return null
  if (!Array.isArray(data.conditions) || data.conditions.length === 0 || data.conditions.length > MAX_CONDITIONS) return null
  const conditions: RuleCondition[] = []
  for (const c of data.conditions) {
    const parsed = parseCondition(c)
    if (parsed === null) return null
    conditions.push(parsed)
  }
  const actions = parseActions(data.actions)
  if (actions === null) return null
  return { id, name, type: type as RuleType, active, order, conditions, actions, createdAtMs: millisOf(data.createdAt) }
}
```

```ts
import 'server-only'
import type { Firestore } from 'firebase-admin/firestore'
import { parseRule } from '@/lib/domain/rules/doc'
import { sortRules } from '@/lib/domain/rules/match'
import type { ActionTargets, ListedRule, Rule, RuleType } from '@/lib/domain/rules/types'
import { unusableActions, withoutUnusableActions } from '@/lib/domain/rules/usable'
import { categoriesCol, counterpartiesCol, rulesCol } from '@/lib/server/ledger/paths'

/** Every readable rule of the company (at most 50) in the order they apply; a malformed document is left out. */
export async function readRules(db: Firestore, orgId: string): Promise<Rule[]> {
  const snap = await rulesCol(db, orgId).get()
  return sortRules(snap.docs.map((d) => parseRule(d.id, d.data())).filter((r): r is Rule => r !== null))
}

function idsOf(rules: readonly Rule[], key: 'categoryId' | 'counterpartyId'): string[] {
  return [...new Set(rules.flatMap((r) => {
    const id = r.actions[key]
    return id === undefined ? [] : [id]
  }))]
}

/** The categories and counterparties the rules' actions name: one `getAll` each, none when nothing is named. */
export async function readTargets(db: Firestore, orgId: string, rules: readonly Rule[]): Promise<ActionTargets> {
  const categoryIds = idsOf(rules, 'categoryId')
  const counterpartyIds = idsOf(rules, 'counterpartyId')
  const [categorySnaps, counterpartySnaps] = await Promise.all([
    categoryIds.length === 0 ? Promise.resolve([]) : db.getAll(...categoryIds.map((id) => categoriesCol(db, orgId).doc(id))),
    counterpartyIds.length === 0 ? Promise.resolve([]) : db.getAll(...counterpartyIds.map((id) => counterpartiesCol(db, orgId).doc(id))),
  ])
  const categories = new Map<string, RuleType>()
  for (const s of categorySnaps) {
    const type: unknown = s.get('type')
    if (s.exists && (type === 'income' || type === 'expense')) categories.set(s.id, type)
  }
  const counterparties = new Map<string, { archived: boolean }>()
  for (const s of counterpartySnaps) if (s.exists) counterparties.set(s.id, { archived: s.get('archived') === true })
  return { categories, counterparties }
}

/** `GET /rules`: every rule in order, with the actions that cannot work now. */
export async function listRules(db: Firestore, orgId: string): Promise<ListedRule[]> {
  const rules = await readRules(db, orgId)
  if (rules.length === 0) return []
  const targets = await readTargets(db, orgId, rules)
  return rules.map((rule) => ({ ...rule, unusable: unusableActions(rule, targets) }))
}

/** What a sync step or an apply step works with: the active rules, their unusable actions removed. */
export async function loadUsableRules(db: Firestore, orgId: string): Promise<Rule[]> {
  const active = (await readRules(db, orgId)).filter((r) => r.active)
  if (active.length === 0) return []
  return withoutUnusableActions(active, await readTargets(db, orgId, active))
}
```

```ts
import 'server-only'
import { Timestamp, type DocumentSnapshot, type Firestore } from 'firebase-admin/firestore'
import { parseRule, ruleToDoc } from '@/lib/domain/rules/doc'
import { RuleError } from '@/lib/domain/rules/errors'
import { withCurrency, type RuleInput, type RulePatch } from '@/lib/domain/rules/input'
import { sortRules } from '@/lib/domain/rules/match'
import { MAX_RULES, type Rule, type RuleType } from '@/lib/domain/rules/types'
import { auditData } from '@/lib/server/ledger/audit'
import { auditCol, categoriesCol, counterpartiesCol, orgRef, rulesCol } from '@/lib/server/ledger/paths'

/** What a rule write needs: Admin Firestore and the clock (the ledger deps have both). */
export interface RuleDeps {
  db: Firestore
  now: () => Date
}

/** The category must exist and have the rule's type; the counterparty must exist and not be archived. */
function assertTargets(type: RuleType, category: DocumentSnapshot | null, counterparty: DocumentSnapshot | null): void {
  if (category !== null && (!category.exists || category.get('type') !== type)) throw new RuleError('category_not_found', 'actions.categoryId')
  if (counterparty !== null) {
    if (!counterparty.exists) throw new RuleError('counterparty_not_found', 'actions.counterpartyId')
    if (counterparty.get('archived') === true) throw new RuleError('counterparty_archived', 'actions.counterpartyId')
  }
}

/** A new rule at the end of the order. The limit, the targets and the write are one transaction. */
export async function createRule(deps: RuleDeps, orgId: string, uid: string, input: RuleInput): Promise<Rule> {
  const col = rulesCol(deps.db, orgId)
  const ref = col.doc()
  return deps.db.runTransaction(async (t) => {
    // All reads first.
    const org = await t.get(orgRef(deps.db, orgId))
    const existing = await t.get(col)
    const category = input.actions.categoryId === undefined ? null : await t.get(categoriesCol(deps.db, orgId).doc(input.actions.categoryId))
    const counterparty = input.actions.counterpartyId === undefined ? null : await t.get(counterpartiesCol(deps.db, orgId).doc(input.actions.counterpartyId))

    if (!org.exists) throw new RuleError('not_found')
    if (existing.size >= MAX_RULES) throw new RuleError('limit_reached')
    assertTargets(input.type, category, counterparty)

    const orders = existing.docs.map((d) => d.get('order')).filter((n): n is number => typeof n === 'number' && Number.isSafeInteger(n))
    const ts = Timestamp.fromDate(deps.now())
    const rule: Rule = {
      id: ref.id,
      name: input.name,
      type: input.type,
      active: input.active,
      order: orders.length === 0 ? 0 : Math.max(...orders) + 1,
      conditions: withCurrency(input.conditions, org.get('currency') as string),
      actions: input.actions,
      createdAtMs: ts.toMillis(),
    }
    t.create(ref, { ...ruleToDoc(rule), orgId, createdAt: ts, createdBy: uid, updatedAt: ts })
    t.create(auditCol(deps.db, orgId).doc(), auditData(deps, 'rule.create', uid, ref.id, null, ruleToDoc(rule)))
    return rule
  })
}

/**
 * Changes what the patch gives. An action is checked again only when it changed (or, for the category, when the type
 * changed): a rule whose category was deleted can still be switched off or renamed, and stays «неробоче».
 */
export async function updateRule(deps: RuleDeps, orgId: string, uid: string, id: string, patch: RulePatch): Promise<Rule> {
  const ref = rulesCol(deps.db, orgId).doc(id)
  return deps.db.runTransaction(async (t) => {
    const snap = await t.get(ref)
    const org = await t.get(orgRef(deps.db, orgId))
    const prior = snap.exists ? parseRule(snap.id, snap.data()) : null
    if (!prior || !org.exists) throw new RuleError('not_found')

    const type = patch.type ?? prior.type
    const actions = patch.actions ?? prior.actions
    const checkCategory = actions.categoryId !== undefined && (actions.categoryId !== prior.actions.categoryId || type !== prior.type)
    const checkCounterparty = actions.counterpartyId !== undefined && actions.counterpartyId !== prior.actions.counterpartyId
    const category = checkCategory ? await t.get(categoriesCol(deps.db, orgId).doc(actions.categoryId as string)) : null
    const counterparty = checkCounterparty ? await t.get(counterpartiesCol(deps.db, orgId).doc(actions.counterpartyId as string)) : null
    assertTargets(type, category, counterparty)

    const after: Rule = {
      ...prior,
      name: patch.name ?? prior.name,
      type,
      active: patch.active ?? prior.active,
      conditions: patch.conditions === undefined ? prior.conditions : withCurrency(patch.conditions, org.get('currency') as string),
      actions,
    }
    // `update` keeps orgId, createdAt and createdBy; `actions` and `conditions` are replaced as whole fields.
    t.update(ref, { ...ruleToDoc(after), updatedAt: Timestamp.fromDate(deps.now()) })
    t.create(auditCol(deps.db, orgId).doc(), auditData(deps, 'rule.update', uid, id, ruleToDoc(prior), ruleToDoc(after)))
    return after
  })
}

/** Removes the rule. The operations it already filled keep their category, counterparty and trace. */
export async function deleteRule(deps: RuleDeps, orgId: string, uid: string, id: string): Promise<void> {
  const ref = rulesCol(deps.db, orgId).doc(id)
  await deps.db.runTransaction(async (t) => {
    const snap = await t.get(ref)
    if (!snap.exists) throw new RuleError('not_found')
    const prior = parseRule(snap.id, snap.data())
    t.delete(ref)
    t.create(auditCol(deps.db, orgId).doc(), auditData(deps, 'rule.delete', uid, id, prior ? ruleToDoc(prior) : (snap.data() ?? null), null))
  })
}

/** Gives the rules the order of `ids`, which must be exactly the company's rules (else `conflict`: the list changed). */
export async function orderRules(deps: RuleDeps, orgId: string, uid: string, ids: readonly string[]): Promise<void> {
  const col = rulesCol(deps.db, orgId)
  await deps.db.runTransaction(async (t) => {
    const snap = await t.get(col)
    const known = new Set(snap.docs.map((d) => d.id))
    if (ids.length !== known.size || new Set(ids).size !== ids.length || ids.some((id) => !known.has(id))) throw new RuleError('conflict')
    const before = sortRules(snap.docs.map((d) => parseRule(d.id, d.data())).filter((r): r is Rule => r !== null)).map((r) => r.id)
    const ts = Timestamp.fromDate(deps.now())
    ids.forEach((id, i) => t.update(col.doc(id), { order: i, updatedAt: ts }))
    t.create(auditCol(deps.db, orgId).doc(), auditData(deps, 'rule.order', uid, 'rules', { ids: before }, { ids: [...ids] }))
  })
}
```

```ts
import { RuleError, type RuleErrorCode } from '@/lib/domain/rules/errors'

const STATUS: Record<RuleErrorCode, number> = {
  invalid_input: 400,
  not_found: 404,
  limit_reached: 409,
  conflict: 409,
  category_not_found: 422,
  counterparty_not_found: 422,
  counterparty_archived: 422,
}

/** A RuleError becomes an HttpError (the code, plus `field` when set); others go to the ledger mapping. */
export function toRuleHttpError(e: unknown): unknown {
  if (e instanceof RuleError) return new HttpError(STATUS[e.code], e.code, e.field === undefined ? undefined : { field: e.field })
  return toHttpError(e)
}
```

```ts
import { isId } from '@/lib/domain/ledger/guards'
import { parseRulePatch } from '@/lib/domain/rules/input'
import { requireOrgRole, requireUser } from '@/lib/server/auth'
import { errorResponse, HttpError } from '@/lib/server/http-error'
import { readJsonBody } from '@/lib/server/request-body'
import { rules } from '@/lib/server/rules'
import { toRuleHttpError } from '@/lib/server/rules/http'

export const runtime = 'nodejs'

const MAX_BODY_BYTES = 32 * 1024
type Ctx = { params: Promise<{ orgId: string; ruleId: string }> }

// PATCH /api/orgs/{orgId}/rules/{ruleId}  (owner, accountant) -> { rule }; also switches `active`
export async function PATCH(req: Request, { params }: Ctx) {
  try {
    const { uid } = await requireUser(req)
    const { orgId, ruleId } = await params
    await requireOrgRole(uid, orgId, ['owner', 'accountant'])
    if (!isId(ruleId)) throw new HttpError(404, 'not_found')
    const patch = parseRulePatch(await readJsonBody(req, MAX_BODY_BYTES))
    const rule = await rules.update(orgId, uid, ruleId, patch)
    return Response.json({ rule }, { headers: { 'Cache-Control': 'no-store' } })
  } catch (e) {
    return errorResponse(toRuleHttpError(e))
  }
}

    const { orgId, ruleId } = await params
    await requireOrgRole(uid, orgId, ['owner', 'accountant'])
    if (!isId(ruleId)) throw new HttpError(404, 'not_found')
    await rules.remove(orgId, uid, ruleId)
    return new Response(null, { status: 204 })
  } catch (e) {
```

```ts
import 'server-only'
import { FieldPath, Timestamp, type Query, type QueryDocumentSnapshot } from 'firebase-admin/firestore'
import { encodeCursor, type JournalKey } from '@/lib/domain/journal/order'
import { parseTransaction } from '@/lib/domain/ledger/doc'
import { LedgerError } from '@/lib/domain/ledger/errors'
import type { TransactionPatch } from '@/lib/domain/ledger/input'
import { RuleError } from '@/lib/domain/rules/errors'
import { withCurrency, type RuleInput } from '@/lib/domain/rules/input'
import { applyRules, ruleOperationOf } from '@/lib/domain/rules/match'
import type { ApplyStepResult, CheckStepResult, PreviewResult, Rule } from '@/lib/domain/rules/types'
import { FxError } from '@/lib/server/fx/types'
import { keyOf } from '@/lib/server/journal/read'
import type { LedgerDeps } from '@/lib/server/ledger/deps'
import { orgRef, transactionsCol } from '@/lib/server/ledger/paths'
import { updateTransaction } from '@/lib/server/ledger/write'
import { loadUsableRules } from './read'

/** Operations one check or apply step reads, in the journal order. */
export const SCAN_PER_STEP = 200
/** Operations one apply step changes at most: one Firestore transaction each, as a bulk change of the journal. */
export const APPLY_PER_STEP = 25
/** Operations «Перевірити» reads at most, in one query. */
export const PREVIEW_CAP = 2000

/** Smaller steps for tests. */
export interface StepLimits {
  scan?: number
  apply?: number
}

/** The journal order (payment date, creation time, id, all descending): the unfiltered journal index serves it. */
function journalOrder(deps: LedgerDeps, orgId: string): Query {
  return transactionsCol(deps.db, orgId).orderBy('paymentDate', 'desc').orderBy('createdAt', 'desc').orderBy(FieldPath.documentId(), 'desc')
}

async function readChunk(deps: LedgerDeps, orgId: string, cursor: JournalKey | null, size: number): Promise<QueryDocumentSnapshot[]> {
  const q = journalOrder(deps, orgId)
  const from = cursor === null ? q : q.startAfter(cursor.paymentDate, new Timestamp(cursor.createdAtS, cursor.createdAtN), cursor.id)
  return (await from.limit(size).get()).docs
}

/**
 * The end of a step. A step that could not place any document it read (no string payment date: a legacy document)
 * cannot move the cursor, so the scan stops there instead of reading the same documents again.
 */
function finish(docs: number, size: number, last: JournalKey | null, cursor: JournalKey | null): { done: boolean; cursor: string | null } {
  const done = docs < size || last === cursor
  return { done, cursor: done || last === null ? null : encodeCursor(last) }
}

/** One step of `check`: what the rules would fill among the next SCAN_PER_STEP operations. Writes nothing. */
export async function checkStep(deps: LedgerDeps, orgId: string, cursor: JournalKey | null, limits: StepLimits = {}): Promise<CheckStepResult> {
  const rules = await loadUsableRules(deps.db, orgId)
  const empty = { scanned: 0, matchOps: 0, categories: 0, counterparties: 0 }
  if (rules.length === 0) return { ...empty, done: true, cursor: null }
  const size = limits.scan ?? SCAN_PER_STEP
  const docs = await readChunk(deps, orgId, cursor, size)
  const counts = { ...empty }
  let last = cursor
  for (const d of docs) {
    counts.scanned++
    last = keyOf(d) ?? last
    const tx = parseTransaction(d.id, d.data())
    if (tx === null) continue
    const outcome = applyRules(rules, ruleOperationOf(tx))
    if (outcome.applied.length === 0) continue
    counts.matchOps++
    if (outcome.categoryId !== undefined) counts.categories++
    if (outcome.counterpartyId !== undefined) counts.counterparties++
  }
  return { ...counts, ...finish(docs.length, size, last, cursor) }
}

/**
 * One step of `apply`: fills what the rules give, at most APPLY_PER_STEP operations, each through `updateTransaction`
 * with the version this step read (`expectVersion`): a person's change after the read wins, the write is a `conflict`
 * and counts as failed. A ledger or rate refusal fails only that operation; anything else aborts the step.
 */
export async function applyStep(deps: LedgerDeps, orgId: string, uid: string, cursor: JournalKey | null, limits: StepLimits = {}): Promise<ApplyStepResult> {
  const rules = await loadUsableRules(deps.db, orgId)
  if (rules.length === 0) return { scanned: 0, changed: 0, failed: 0, done: true, cursor: null }
  const size = limits.scan ?? SCAN_PER_STEP
  const most = limits.apply ?? APPLY_PER_STEP
  const docs = await readChunk(deps, orgId, cursor, size)
  let scanned = 0
  let changed = 0
  let failed = 0
  let last = cursor
  let full = false
  for (const d of docs) {
    if (changed + failed >= most) {
      full = true
      break
    }
    scanned++
    last = keyOf(d) ?? last
    const tx = parseTransaction(d.id, d.data())
    if (tx === null) continue
    const outcome = applyRules(rules, ruleOperationOf(tx))
    if (outcome.applied.length === 0) continue
    const patch: TransactionPatch = {}
    if (outcome.categoryId !== undefined) patch.categoryId = outcome.categoryId
    if (outcome.counterpartyId !== undefined) patch.counterpartyId = outcome.counterpartyId
    try {
      await updateTransaction(deps, orgId, uid, tx.id, patch, { autoRules: outcome.applied, expectVersion: d.updateTime })
      changed++
    } catch (e) {
      if (!(e instanceof LedgerError || e instanceof FxError)) throw e
      failed++
    }
  }
  if (full) return { scanned, changed, failed, done: false, cursor: last === null ? null : encodeCursor(last) }
  return { scanned, changed, failed, ...finish(docs.length, size, last, cursor) }
}

/**
 * «Перевірити»: reads the latest `cap` operations in one query and counts, among the ones without a category or a
 * counterparty, how many the draft rule would fill. Firestore cannot ask for a missing field, so the cap applies to
 * the operations read; `capped` says the query was full. Writes nothing; the rule's `active` is ignored.
 */
export async function previewRule(deps: LedgerDeps, orgId: string, input: RuleInput, cap = PREVIEW_CAP): Promise<PreviewResult> {
  const org = await orgRef(deps.db, orgId).get()
  if (!org.exists) throw new RuleError('not_found')
  const rule: Rule = {
    id: 'preview',
    name: input.name,
    type: input.type,
    active: true,
    order: 0,
    createdAtMs: 0,
    conditions: withCurrency(input.conditions, org.get('currency') as string),
    actions: input.actions,
  }
  const snap = await journalOrder(deps, orgId).limit(cap).get()
  let scanned = 0
  let matched = 0
  for (const d of snap.docs) {
    const tx = parseTransaction(d.id, d.data())
    if (tx === null || tx.type === 'transfer' || (tx.categoryId !== undefined && tx.counterpartyId !== undefined)) continue
    scanned++
    if (applyRules([rule], ruleOperationOf(tx)).applied.length > 0) matched++
  }
  return { matched, scanned, capped: snap.size === cap }
}
```

```ts
async function step<T>(orgId: string, body: Record<string, unknown>, signal?: AbortSignal): Promise<T> {
  const res = await fetch(`${base(orgId)}/apply`, {
    method: 'POST',
    credentials: 'same-origin',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(body),
    signal,
  })
  if (!res.ok) throw await readApiError(res)
  return (await res.json()) as T
}

export interface CheckTotals {
  scanned: number
  matchOps: number
  categories: number
  counterparties: number
}

/** Counts, step by step, what «Застосувати до наявних» would change. Writes nothing. */
export async function checkExisting(
  orgId: string,
  opts: { signal?: AbortSignal; onProgress?: (totals: CheckTotals) => void } = {},
): Promise<CheckTotals> {
  const totals: CheckTotals = { scanned: 0, matchOps: 0, categories: 0, counterparties: 0 }
  let cursor: string | null = null
  for (let i = 0; i < MAX_STEPS; i++) {
    const answer: CheckStepResult = await step<CheckStepResult>(orgId, cursor === null ? { mode: 'check' } : { mode: 'check', cursor }, opts.signal)
    totals.scanned += answer.scanned
    totals.matchOps += answer.matchOps
    totals.categories += answer.categories
    totals.counterparties += answer.counterparties
    if (answer.done || answer.cursor === null) break
    cursor = answer.cursor
    opts.onProgress?.({ ...totals })
  }
  return totals
}

export interface ApplyTotals {
  scanned: number
  changed: number
  failed: number
}

/** Runs «Застосувати до наявних» to the end; the journal reloads once when something changed. */
export async function applyToExisting(
  orgId: string,
  opts: { signal?: AbortSignal; onProgress?: (totals: ApplyTotals) => void } = {},
): Promise<ApplyTotals> {
  const totals: ApplyTotals = { scanned: 0, changed: 0, failed: 0 }
  let cursor: string | null = null
  try {
    for (let i = 0; i < MAX_STEPS; i++) {
      const answer: ApplyStepResult = await step<ApplyStepResult>(orgId, cursor === null ? { mode: 'apply' } : { mode: 'apply', cursor }, opts.signal)
      totals.scanned += answer.scanned
      totals.changed += answer.changed
      totals.failed += answer.failed
      if (answer.done || answer.cursor === null) break
      cursor = answer.cursor
      opts.onProgress?.({ ...totals })
    }
  } finally {
    if (totals.changed > 0) notifyLedgerChanged()
  }
  return totals
}
```

```ts
import { fromMinor, toMinor } from '@/lib/domain/ledger/money'
import type { RuleConditionInput, RuleInput } from '@/lib/domain/rules/input'
import { MAX_VALUES, type Rule, type RuleType, type TextOp } from '@/lib/domain/rules/types'
import type { Locale } from '@/lib/i18n/config'
import { formatAmountInput, parseAmountInput } from '@/lib/utils/amount-input'

/** One condition as the editor holds it: the words and the amounts as typed. */
export type DraftCondition =
  | { kind: 'text'; op: TextOp; values: string }
  | { kind: 'account'; accountIds: string[] }
  | { kind: 'amount'; currency: string; min: string; max: string }

export interface RuleDraft {
  name: string
  type: RuleType
  active: boolean
  conditions: DraftCondition[]
  /** '' sets no category. */
  categoryId: string
  counterpartyId: string | null
}

/** An empty condition of a kind; an amount starts in `currency` (the company currency, '' while it loads). */
export function newCondition(kind: DraftCondition['kind'], currency: string): DraftCondition {
  if (kind === 'text') return { kind: 'text', op: 'contains', values: '' }
  if (kind === 'account') return { kind: 'account', accountIds: [] }
  return { kind: 'amount', currency, min: '', max: '' }
}

/** A new rule: an expense with one empty text condition (bank rules are mostly about expenses). */
export function emptyDraft(): RuleDraft {
  return { name: '', type: 'expense', active: true, conditions: [newCondition('text', '')], categoryId: '', counterpartyId: null }
}

/** The words of a text condition: split at commas, semicolons and line breaks, trimmed, empty ones dropped. */
export function splitValues(text: string): string[] {
  return text
    .split(/[,;\n]/)
    .map((v) => v.trim())
    .filter((v) => v !== '')
}

export function draftFromRule(rule: Rule, locale: Locale): RuleDraft {
  const amount = (minor: number | undefined) => (minor === undefined ? '' : formatAmountInput(fromMinor(minor), locale))
  return {
    name: rule.name,
    type: rule.type,
    active: rule.active,
    conditions: rule.conditions.map((c): DraftCondition => {
      if (c.kind === 'text') return { kind: 'text', op: c.op, values: c.values.join(', ') }
      if (c.kind === 'account') return { kind: 'account', accountIds: [...c.accountIds] }
      return { kind: 'amount', currency: c.currency, min: amount(c.minMinor), max: amount(c.maxMinor) }
    }),
    categoryId: rule.actions.categoryId ?? '',
    counterpartyId: rule.actions.counterpartyId ?? null,
  }
}

/** undefined for an empty field, null for text that is not an amount. */
function minorOf(text: string): number | undefined | null {
  if (text.trim() === '') return undefined
  const value = parseAmountInput(text)
  return value === null ? null : toMinor(value)
}

/** The request body of the draft, or null while it is not complete (the server checks everything again). */
export function draftToInput(d: RuleDraft): RuleInput | null {
  const name = d.name.trim()
  if (name === '' || d.conditions.length === 0) return null
  if (d.categoryId === '' && d.counterpartyId === null) return null
  const conditions: RuleConditionInput[] = []
  for (const c of d.conditions) {
    if (c.kind === 'text') {
      const values = splitValues(c.values)
      if (values.length === 0 || values.length > MAX_VALUES) return null
      conditions.push({ kind: 'text', op: c.op, values })
    } else if (c.kind === 'account') {
      if (c.accountIds.length === 0) return null
      conditions.push({ kind: 'account', accountIds: [...c.accountIds] })
    } else {
      const minMinor = minorOf(c.min)
      const maxMinor = minorOf(c.max)
      if (minMinor === null || maxMinor === null || (minMinor === undefined && maxMinor === undefined)) return null
      conditions.push({
        kind: 'amount',
```

```ts
'use client'

import { useCallback, useEffect, useState } from 'react'
import { fetchRules } from '@/lib/api/rules-client'
import type { ListedRule } from '@/lib/domain/rules/types'

const EMPTY: ListedRule[] = []

interface Loaded {
  orgId: string
  rules: ListedRule[]
}

/** The company's rules as the server lists them (in order, with the «неробоче» marks); `reload` after a change. */
export function useRules(orgId: string) {
  // Stored with its company, so a company switch never shows the previous company's rules.
  const [loaded, setLoaded] = useState<Loaded | null>(null)
  const [failedFor, setFailedFor] = useState<string | null>(null)
  const [tick, setTick] = useState(0)
  const reload = useCallback(() => setTick((n) => n + 1), [])

  useEffect(() => {
    const controller = new AbortController()
    fetchRules(orgId, controller.signal).then(
      (rules) => {
        setLoaded({ orgId, rules })
        setFailedFor(null)
      },
      () => {
        if (!controller.signal.aborted) setFailedFor(orgId)
      },
    )
    return () => controller.abort()
  }, [orgId, tick])

  const rules = loaded !== null && loaded.orgId === orgId ? loaded.rules : null
  return { rules: rules ?? EMPTY, loading: rules === null && failedFor !== orgId, error: rules === null && failedFor === orgId, reload }
}
```

```tsx
'use client'

import { useTranslations } from 'next-intl'
import type { Counterparty } from '@/lib/domain/counterparties/types'
import { fromMinor } from '@/lib/domain/ledger/money'
import type { ListedRule, RuleCondition } from '@/lib/domain/rules/types'
import { useCategoryName } from '@/lib/i18n/useCategoryName'
import { useFormatters } from '@/lib/i18n/useFormatters'
import type { Account, Category } from '@/types'

interface Props {
  rule: ListedRule
  accounts: Account[]
  categories: Category[]
  counterparties: Counterparty[]
}

/** One line under the rule's name: what it checks, then what it sets. A deleted account, category or counterparty reads «(видалено)». */
export function RuleSummary({ rule, accounts, categories, counterparties }: Props) {
  const t = useTranslations('settings.rules.summary')
  const { money } = useFormatters()
  const categoryName = useCategoryName()

  const condition = (c: RuleCondition): string => {
    if (c.kind === 'text') return t(c.op, { values: c.values.join(', ') })
    if (c.kind === 'account') {
      return t('account', { names: c.accountIds.map((id) => accounts.find((a) => a.id === id)?.name ?? t('missing')).join(', ') })
    }
    const min = c.minMinor === undefined ? null : money(fromMinor(c.minMinor), c.currency)
    const max = c.maxMinor === undefined ? null : money(fromMinor(c.maxMinor), c.currency)
    if (min !== null && max !== null) return t('amountRange', { min, max })
    return min !== null ? t('amountMin', { min }) : t('amountMax', { max: max ?? '' })
  }

  const { categoryId, counterpartyId } = rule.actions
  const category = categoryId === undefined ? undefined : categories.find((c) => c.id === categoryId)
  const counterparty = counterpartyId === undefined ? undefined : counterparties.find((c) => c.id === counterpartyId)
  const actions: string[] = []
  if (categoryId !== undefined) actions.push(t('category', { name: category ? categoryName(category) : t('missing') }))
  if (counterpartyId !== undefined) actions.push(t('counterparty', { name: counterparty?.name ?? t('missing') }))

  return (
    <p className="text-xs text-ink-muted">
      {rule.conditions.map(condition).join(' · ')} → {actions.join(', ')}
    </p>
  )
}
```

```tsx
  /** The company currency: a new amount condition starts in it ('' while the company loads; the server then fills it). */
  currency: string
  onClose: () => void
  /** After a save or a delete: the list is read again. */
  onSaved: () => void
}

type Busy = 'save' | 'delete' | 'check' | null

/** The rule editor: name, type, conditions, actions and «Перевірити» against the existing operations. */
export function RuleEditor({ orgId, rule, accounts, incomeCategories, expenseCategories, counterparties, currency, onClose, onSaved }: Props) {
  const t = useTranslations('settings.rules')
  const tCommon = useTranslations('common')
  const locale = useLocale() as Locale
  const categoryName = useCategoryName()
  const [draft, setDraft] = useState<RuleDraft>(() => (rule ? draftFromRule(rule, locale) : emptyDraft()))
  const [busy, setBusy] = useState<Busy>(null)
  // The answer of «Перевірити»; any change of the draft makes it stale, so it is cleared.
  const [check, setCheck] = useState<PreviewResult | null>(null)

  const input = draftToInput(draft)
  const categories = draft.type === 'income' ? incomeCategories : expenseCategories
  const missingCategory = draft.categoryId !== '' && !categories.some((c) => c.id === draft.categoryId)

  const change = (next: Partial<RuleDraft>) => {
    setDraft((d) => ({ ...d, ...next }))
    setCheck(null)
  }
  const changeCondition = (index: number, next: DraftCondition) => change({ conditions: draft.conditions.map((c, i) => (i === index ? next : c)) })

  const errorText = (e: unknown): string => {
    const code = e instanceof LedgerApiError ? e.code : ''
    if (code === 'category_not_found') return t('errors.category')
    if (code === 'counterparty_not_found') return t('errors.counterpartyMissing')
    if (code === 'counterparty_archived') return t('errors.counterpartyArchived')
    if (code === 'limit_reached') return t('errors.limit')
    if (code === 'not_found') return t('errors.gone')
    if (code === 'invalid_input') return t('errors.invalid')
    return t('errors.save')
  }

  const save = async (e: FormEvent) => {
    e.preventDefault()
    if (input === null || busy !== null) return
    setBusy('save')
    try {
      if (rule) await updateRule(orgId, rule.id, input)
      else await createRule(orgId, input)
      toast.success(t('saved'))
      onSaved()
      onClose()
    } catch (err) {
      toast.error(errorText(err))
      setBusy(null)
    }
  }

  const runCheck = async () => {
    if (input === null) return
    setBusy('check')
    try {
      setCheck(await previewRule(orgId, input))
    } catch {
      toast.error(t('errors.check'))
    } finally {
      setBusy(null)
    }
  }

  const remove = async () => {
    if (!rule || !window.confirm(t('editor.deleteConfirm', { name: rule.name }))) return
    setBusy('delete')
    try {
      await deleteRule(orgId, rule.id)
      toast.success(t('deleted'))
      onSaved()
      onClose()
    } catch (err) {
      toast.error(errorText(err))
      setBusy(null)
    }
  }

  return (
    <Dialog open onOpenChange={(open) => !open && onClose()}>
      <DialogContent className="max-h-[90dvh] overflow-y-auto sm:max-w-lg">
        <DialogHeader>
          <DialogTitle>{rule ? t('editor.titleEdit') : t('editor.titleNew')}</DialogTitle>
        </DialogHeader>
        <form onSubmit={save} className="space-y-4" noValidate>
          <div className="space-y-1">
            <Label htmlFor="rule-name">{t('editor.name')}</Label>
            <Input id="rule-name" maxLength={100} value={draft.name} onChange={(e) => change({ name: e.target.value })} />
          </div>

          <div className="flex flex-wrap items-center justify-between gap-3">
            <Segmented
              label={t('editor.type')}
              value={draft.type}
              onChange={(type) => {
                // A category belongs to one type: switching the type drops the chosen one.
                if (type !== draft.type) change({ type, categoryId: '' })
              }}
              options={[
                { value: 'expense', label: t('type.expense') },
                { value: 'income', label: t('type.income') },
              ]}
            />
            <label className="flex items-center gap-2 text-sm text-ink">
              <input type="checkbox" className="accent-brand" checked={draft.active} onChange={(e) => change({ active: e.target.checked })} />
              {t('editor.active')}
            </label>
          </div>

          <fieldset className="space-y-3">
            <legend className="text-sm font-medium text-ink">{t('editor.conditions')}</legend>
            {draft.conditions.map((c, i) => (
              <ConditionRow
                key={i}
                index={i}
                condition={c}
                accounts={accounts}
                currency={currency}
                onChange={(next) => changeCondition(i, next)}
                onRemove={draft.conditions.length > 1 ? () => change({ conditions: draft.conditions.filter((_, j) => j !== i) }) : undefined}
              />
            ))}
            <Button
              type="button"
              variant="outline"
              size="sm"
              disabled={draft.conditions.length >= MAX_CONDITIONS}
              onClick={() => change({ conditions: [...draft.conditions, newCondition('text', currency)] })}
            >
              <Plus />
              {t('editor.addCondition')}
            </Button>
          </fieldset>

          <fieldset className="space-y-3">
            <legend className="text-sm font-medium text-ink">{t('editor.actions')}</legend>
            <div className="space-y-1">
              <Label htmlFor="rule-category">{t('editor.category')}</Label>
              <NativeSelect id="rule-category" value={draft.categoryId} onChange={(e) => change({ categoryId: e.target.value })}>
                <option value="">{t('editor.noCategory')}</option>

                id="rule-counterparty"
                counterparties={counterparties.filter((c) => !c.archived || c.id === draft.counterpartyId)}
                value={draft.counterpartyId}
                onChange={(id) => change({ counterpartyId: id })}
              />
            </div>
          </fieldset>

          <div className="space-y-2">
            <Button type="button" variant="soft" onClick={() => void runCheck()} disabled={input === null || busy !== null}>
              {busy === 'check' ? t('editor.checking') : t('editor.check')}
            </Button>
            {check && (
              <p data-testid="rule-check-result" className="text-sm text-ink" aria-live="polite">
                {t('editor.checkResult', { scanned: check.scanned, matched: check.matched })}
                {check.capped && <span className="block text-xs text-ink-muted">{t('editor.checkCapped')}</span>}
              </p>
            )}
          </div>

          <DialogFooter className="gap-2 sm:justify-between">
            {rule ? (
              <Button type="button" variant="ghost" className="text-expense" onClick={() => void remove()} disabled={busy !== null}>
                {tCommon('delete')}
              </Button>
            ) : (

                {tCommon('cancel')}
              </Button>

                {busy === 'save' ? t('editor.saving') : tCommon('save')}
              </Button>
            </div>
          </DialogFooter>
        </form>
      </DialogContent>
    </Dialog>
  )
}
```

```tsx
'use client'

import { useEffect, useRef, useState } from 'react'
import { useTranslations } from 'next-intl'
import { Button } from '@/components/ui/button'
import { Dialog, DialogContent, DialogDescription, DialogFooter, DialogHeader, DialogTitle } from '@/components/ui/dialog'
import { applyToExisting, checkExisting, type ApplyTotals, type CheckTotals } from '@/lib/api/rules-client'

interface Props {
  orgId: string
  onClose: () => void
}

type Phase =
  | { kind: 'checking'; scanned: number }
  | { kind: 'ready'; totals: CheckTotals }
  | { kind: 'applying'; changed: number }
  | { kind: 'done'; totals: ApplyTotals }
  | { kind: 'failed' }

/**
 * «Застосувати до наявних»: counts first («буде змінено N»), applies after the confirmation with the progress, then the
 * summary. Mounted only while open, so every opening counts afresh.
 */
export function ApplyRulesDialog({ orgId, onClose }: Props) {
  const t = useTranslations('settings.rules.apply')
  const tCommon = useTranslations('common')
  const [phase, setPhase] = useState<Phase>({ kind: 'checking', scanned: 0 })
  const running = useRef<AbortController | null>(null)

  useEffect(() => {
    const controller = new AbortController()
    running.current = controller
    checkExisting(orgId, { signal: controller.signal, onProgress: (p) => setPhase({ kind: 'checking', scanned: p.scanned }) }).then(
      (totals) => setPhase({ kind: 'ready', totals }),
      () => {
        if (!controller.signal.aborted) setPhase({ kind: 'failed' })
      },
    )
    return () => controller.abort()
  }, [orgId])

  const apply = async () => {
    const controller = new AbortController()
    running.current = controller
    setPhase({ kind: 'applying', changed: 0 })
    try {
      const totals = await applyToExisting(orgId, { signal: controller.signal, onProgress: (p) => setPhase({ kind: 'applying', changed: p.changed }) })
      setPhase({ kind: 'done', totals })
    } catch {
      if (!controller.signal.aborted) setPhase({ kind: 'failed' })
    }
  }

  /** Closing stops the next step; a step already sent finishes on the server (it is safe to repeat). */
  const close = () => {
    running.current?.abort()
    onClose()
  }

  const finished = phase.kind === 'done' || phase.kind === 'failed'

  return (
    <Dialog open onOpenChange={(open) => !open && close()}>
      <DialogContent className="sm:max-w-md">
        <DialogHeader>
          <DialogTitle>{t('title')}</DialogTitle>
          <DialogDescription>{t('note')}</DialogDescription>
        </DialogHeader>
        <div data-testid="rules-apply-state" className="space-y-1 text-sm text-ink" aria-live="polite">
          {phase.kind === 'checking' && <p>{t('checking', { scanned: phase.scanned })}</p>}
          {phase.kind === 'ready' &&
            (phase.totals.matchOps === 0 ? (
              <p>{t('nothing')}</p>
            ) : (
              <>
                <p className="font-medium">{t('willChange', { count: phase.totals.matchOps })}</p>
                <p className="text-ink-muted">{t('breakdown', { categories: phase.totals.categories, counterparties: phase.totals.counterparties })}</p>
              </>
            ))}
          {phase.kind === 'applying' && <p>{t('running', { changed: phase.changed })}</p>}
          {phase.kind === 'done' && (
            <>
              <p className="font-medium">{t('done', { changed: phase.totals.changed })}</p>
              {phase.totals.failed > 0 && <p className="text-expense">{t('failed', { failed: phase.totals.failed })}</p>}
            </>
          )}
          {phase.kind === 'failed' && <p className="text-expense">{t('error')}</p>}
        </div>
        <DialogFooter>
          <Button data-testid="rules-apply-close" variant="outline" onClick={close}>
            {finished ? tCommon('close') : tCommon('cancel')}
          </Button>
          {phase.kind === 'ready' && phase.totals.matchOps > 0 && (
            <Button data-testid="rules-apply-confirm" onClick={() => void apply()}>
              {t('confirm')}
            </Button>
          )}
        </DialogFooter>
      </DialogContent>
    </Dialog>
  )
}
```
